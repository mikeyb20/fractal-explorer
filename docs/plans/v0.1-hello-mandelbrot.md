# Fractal Explorer — v0.1 hello-Mandelbrot (detailed)

## Context

Workspace holds one empty `fractal-core` crate (`src/lib.rs` is a stub with a trivial test). `VISION.md` defines a broad v1 (Julia preview, WebGPU+WebGL2, tour, gallery, multi-palette, keyboard+touch, responsive). That is a Tier-2 multi-workstream undertaking.

This plan carves a **v0.1 "hello-Mandelbrot" slice** — enough to see the Mandelbrot in the browser, drag it, zoom it, and share the URL. The goal is to de-risk the full pipeline (Rust → WASM → trunk → wgpu → WebGPU → `<canvas>`) before layering UX.

**Target outcome:** `trunk serve` → Mandelbrot fills viewport → mouse drag pans → wheel zooms toward cursor → pasted URL restores exact view → unsupported browsers show a readable error instead of a white screen.

---

## Scope

### In (v0.1)

- `fractal-core`: `Fractal` trait, `Mandelbrot` impl, `Viewport` math (f32 GPU, f64 state), smooth iteration count, one baked-in palette, WGSL shader-source assembly.
- `fractal-web` (new crate): WASM entry, wgpu-on-WebGPU renderer, DPR-aware canvas resize, pointer-drag pan, wheel zoom-toward-cursor, URL hash state sync, "WebGPU required" error overlay.

### Out (deferred, roadmap at the bottom)

Julia preview, WebGL2 fallback, tour mode, gallery, palette picker, screenshot, keyboard shortcuts, touch gestures (pinch), multi-palette, desktop features, golden-image tests, perf budget validation.

### `src/viewport.rs`

Zoom convention: `zoom` is the **half-width** of the view in complex-plane units. Default Mandelbrot view is `center = (-0.5, 0.0)`, `zoom = 1.5` (so x-range ≈ [-2.0, 1.0]). Y is flipped on screen (screen y-down vs complex-plane y-up).

```rust
use bytemuck::{Pod, Zeroable};

#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Viewport {
    pub center: (f64, f64),
    pub zoom: f64,            // half-width in complex units
    pub aspect_ratio: f32,    // width / height
}

impl Viewport {
    pub const MANDELBROT_DEFAULT: Self = Self {
        center: (-0.5, 0.0),
        zoom: 1.5,
        aspect_ratio: 1.0,
    };

    /// Map pixel (0..width, 0..height) to complex plane.
    pub fn pixel_to_complex(&self, pixel: (f32, f32), size: (u32, u32)) -> (f64, f64) {
        let nx = (pixel.0 as f64 / size.0 as f64) * 2.0 - 1.0;
        let ny = 1.0 - (pixel.1 as f64 / size.1 as f64) * 2.0;
        let half_w = self.zoom;
        let half_h = self.zoom / self.aspect_ratio as f64;
        (self.center.0 + nx * half_w, self.center.1 + ny * half_h)
    }

    /// Zoom by factor (factor < 1 zooms in) keeping `pixel` at the same complex point.
    pub fn zoom_toward(&mut self, pixel: (f32, f32), size: (u32, u32), factor: f64) {
        let before = self.pixel_to_complex(pixel, size);
        self.zoom *= factor;
        let after = self.pixel_to_complex(pixel, size);
        self.center.0 += before.0 - after.0;
        self.center.1 += before.1 - after.1;
    }

    /// Pan by a pixel delta (e.g. drag movement). Dragging right moves the image right
    /// (i.e. center moves left).
    pub fn pan_by_pixels(&mut self, delta: (f32, f32), size: (u32, u32)) {
        let half_w = self.zoom;
        let half_h = self.zoom / self.aspect_ratio as f64;
        let dx = (delta.0 as f64 / size.0 as f64) * 2.0 * half_w;
        let dy = (delta.1 as f64 / size.1 as f64) * 2.0 * half_h;
        self.center.0 -= dx;
        self.center.1 += dy; // screen-y down → complex-y up
    }
}

#[repr(C)]
#[derive(Clone, Copy, Pod, Zeroable)]
pub struct Uniforms {
    pub center: [f32; 2],
    pub zoom: f32,
    pub aspect: f32,
    pub iter_cap: u32,
    pub _pad: [u32; 3],   // std140/uniform alignment: 16-byte multiples
}

impl Uniforms {
    pub fn from_viewport(vp: &Viewport, iter_cap: u32) -> Self {
        Self {
            center: [vp.center.0 as f32, vp.center.1 as f32],
            zoom: vp.zoom as f32,
            aspect: vp.aspect_ratio,
            iter_cap,
            _pad: [0; 3],
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    fn vp() -> Viewport {
        Viewport { center: (0.0, 0.0), zoom: 1.0, aspect_ratio: 1.0 }
    }

    #[test]
    fn pixel_center_maps_to_complex_center() {
        let p = vp().pixel_to_complex((50.0, 50.0), (100, 100));
        assert!((p.0).abs() < 1e-9 && (p.1).abs() < 1e-9);
    }

    #[test]
    fn pixel_corners_map_to_plane_corners() {
        let v = vp();
        let tl = v.pixel_to_complex((0.0, 0.0), (100, 100));
        let br = v.pixel_to_complex((100.0, 100.0), (100, 100));
        assert!((tl.0 + 1.0).abs() < 1e-9 && (tl.1 - 1.0).abs() < 1e-9);
        assert!((br.0 - 1.0).abs() < 1e-9 && (br.1 + 1.0).abs() < 1e-9);
    }

    fn zoom_toward_fixed_point_invariant() {

        v.zoom_toward(pixel, size, 0.5);
        let after = v.pixel_to_complex(pixel, size);

        assert!((before.1 - after.1).abs() < 1e-9);
```

### `src/fractals/mandelbrot.rs`

```rust
use crate::fractal::Fractal;
use crate::viewport::Viewport;

pub struct Mandelbrot;

const MANDELBROT_WGSL: &str = r#"
fn iter(c: vec2<f32>, iter_cap: u32) -> f32 {
    var z = vec2<f32>(0.0, 0.0);
    var i: u32 = 0u;
    let bailout_sq: f32 = 256.0;
    loop {
        if (i >= iter_cap) { break; }
        let zx = z.x * z.x - z.y * z.y + c.x;
        let zy = 2.0 * z.x * z.y + c.y;
        z = vec2<f32>(zx, zy);
        let mag2 = z.x * z.x + z.y * z.y;
        if (mag2 > bailout_sq) {
            // Smooth iteration count: n + 1 - log2(log2(|z|))
            let log_zn = log(mag2) * 0.5;              // = log|z|
            let nu = log(log_zn / 0.693147) / 0.693147; // log2(log_zn)
            return f32(i) + 1.0 - nu;
        }
        i = i + 1u;
    }
    return -1.0;
}
"#;

impl Fractal for Mandelbrot {
    fn id(&self) -> &'static str { "mandelbrot" }
    fn display_name(&self) -> &'static str { "Mandelbrot" }
    fn default_view(&self) -> Viewport { Viewport::MANDELBROT_DEFAULT }
    fn default_iter_cap(&self) -> u32 { 256 }
    fn wgsl_iter_snippet(&self) -> &'static str { MANDELBROT_WGSL }
}
```

```rust
/// "Electric" palette — smooth cosine-based gradient, `t` in [0,1].
pub const DEFAULT_PALETTE_WGSL: &str = r#"
fn palette(t: f32) -> vec3<f32> {
    let tt = sqrt(clamp(t, 0.0, 1.0));
    let tau = 6.2831853;
    return vec3<f32>(
        0.5 + 0.5 * cos(tau * (tt + 0.00)),
        0.5 + 0.5 * cos(tau * (tt + 0.33)),
        0.5 + 0.5 * cos(tau * (tt + 0.67))
    );
}
"#;
```

### `src/shader.rs`

```rust
use crate::coloring::DEFAULT_PALETTE_WGSL;
use crate::fractal::Fractal;

const TEMPLATE: &str = r#"
struct Uniforms {
    center: vec2<f32>,
    zoom: f32,
    aspect: f32,
    iter_cap: u32,
    _pad0: u32, _pad1: u32, _pad2: u32,
};

@group(0) @binding(0) var<uniform> u: Uniforms;

struct VsOut {
    @builtin(position) pos: vec4<f32>,
    @location(0) uv: vec2<f32>,
};

@vertex
fn vs_main(@builtin(vertex_index) idx: u32) -> VsOut {
    // Fullscreen triangle (covers the [-1,1] clip space)
    let x = f32((idx << 1u) & 2u);
    let y = f32(idx & 2u);
    var out: VsOut;
    out.pos = vec4<f32>(x * 2.0 - 1.0, y * 2.0 - 1.0, 0.0, 1.0);
    out.uv = vec2<f32>(x, y);
    return out;
}

__ITER_SNIPPET__

__PALETTE_SNIPPET__

@fragment
fn fs_main(in: VsOut) -> @location(0) vec4<f32> {
    let nx = in.uv.x * 2.0 - 1.0;
    let ny = 1.0 - in.uv.y * 2.0;
    let half_w = u.zoom;
    let half_h = u.zoom / u.aspect;
    let c = vec2<f32>(u.center.x + nx * half_w, u.center.y + ny * half_h);
    let t = iter(c, u.iter_cap);
    if (t < 0.0) {
        return vec4<f32>(0.0, 0.0, 0.0, 1.0);
    }
    return vec4<f32>(palette(t / f32(u.iter_cap)), 1.0);
}
"#;

pub fn build_shader(fractal: &dyn Fractal) -> String {
    TEMPLATE
        .replace("__ITER_SNIPPET__", fractal.wgsl_iter_snippet())
        .replace("__PALETTE_SNIPPET__", DEFAULT_PALETTE_WGSL)
}

#[cfg(test)]
mod tests {
    use super::*;
    use crate::fractals::mandelbrot::Mandelbrot;

    #[test]
    fn mandelbrot_shader_parses() {
        let src = build_shader(&Mandelbrot);
        let module = naga::front::wgsl::parse_str(&src)
            .unwrap_or_else(|e| panic!("WGSL parse error: {e}\n---\n{src}"));
        // Sanity: must have vs_main and fs_main entry points
        let names: Vec<_> = module.entry_points.iter().map(|e| e.name.as_str()).collect();
        assert!(names.contains(&"vs_main"));
        assert!(names.contains(&"fs_main"));
    }
}
```

```rust
#[wasm_bindgen(start)]
pub fn start() {
    console_error_panic_hook::set_once();
    let _ = console_log::init_with_level(log::Level::Info);
    wasm_bindgen_futures::spawn_local(async move {
        if let Err(e) = run().await {
            log::error!("fatal: {e:?}");
            error_overlay::show(&format!("{e}"));
        }
    });

async fn run() -> Result<(), AppError> {
    let window = web_sys::window().ok_or(AppError::NoWindow)?;
    let document = window.document().ok_or(AppError::NoDocument)?;
    let canvas = document
        .get_element_by_id("fractal")
        .ok_or(AppError::NoCanvas)?
        .dyn_into::<web_sys::HtmlCanvasElement>()
        .map_err(|_| AppError::NoCanvas)?;

    // Fractal + initial viewport from URL (or defaults).
    let fractal = fractal_core::Mandelbrot;
    let (mut viewport, mut iter_cap) = state::load_initial(&window, &fractal);

    let (width, height) = util::canvas_size_px(&canvas, &window);
    viewport.aspect_ratio = width as f32 / height as f32;

    let mut renderer = renderer::Renderer::new(&canvas, width, height, &fractal).await?;
    renderer.draw(&viewport, iter_cap);

    input::install(&canvas, &window, viewport, iter_cap, renderer, fractal);

    Ok(())
}

#[derive(thiserror::Error, Debug)]
```

### `src/renderer.rs` (sketch)

```rust
use fractal_core::{Fractal, Viewport, build_shader, viewport::Uniforms};
use wgpu::util::DeviceExt;

pub struct Renderer {
    surface: wgpu::Surface<'static>,
    device: wgpu::Device,
    queue: wgpu::Queue,
    config: wgpu::SurfaceConfiguration,
    pipeline: wgpu::RenderPipeline,
    bind_group: wgpu::BindGroup,
    uniform_buf: wgpu::Buffer,
}

impl Renderer {
    pub async fn new(
        canvas: &web_sys::HtmlCanvasElement,
        width: u32,
        height: u32,
        fractal: &dyn Fractal,
    ) -> Result<Self, crate::AppError> {
        // Bail early if navigator.gpu is missing
        if js_sys::Reflect::get(&web_sys::window().unwrap().navigator(), &"gpu".into())
            .map(|v| v.is_undefined())
            .unwrap_or(true)
        {
            return Err(crate::AppError::NoWebGpu);
        }

        let instance = wgpu::Instance::new(wgpu::InstanceDescriptor {
            backends: wgpu::Backends::BROWSER_WEBGPU,
            ..Default::default()
        });
        let surface = instance
            .create_surface(wgpu::SurfaceTarget::Canvas(canvas.clone()))
            .map_err(|e| crate::AppError::Surface(e.to_string()))?;

        let adapter = instance
            .request_adapter(&wgpu::RequestAdapterOptions {
                power_preference: wgpu::PowerPreference::HighPerformance,
                compatible_surface: Some(&surface),
                force_fallback_adapter: false,
            })
            .await
            .ok_or(crate::AppError::NoAdapter)?;

        let (device, queue) = adapter
            .request_device(&wgpu::DeviceDescriptor::default(), None)
            .await
            .map_err(|e| crate::AppError::Device(e.to_string()))?;

        let config = surface
            .get_default_config(&adapter, width, height)
            .ok_or(crate::AppError::Surface("no default config".into()))?;
        surface.configure(&device, &config);

        let shader_src = build_shader(fractal);
        let shader = device.create_shader_module(wgpu::ShaderModuleDescriptor {
            label: Some("fractal-shader"),
            source: wgpu::ShaderSource::Wgsl(shader_src.into()),
        });

        let uniform_buf = device.create_buffer(&wgpu::BufferDescriptor {
            label: Some("uniforms"),
            size: std::mem::size_of::<Uniforms>() as u64,
            usage: wgpu::BufferUsages::UNIFORM | wgpu::BufferUsages::COPY_DST,
            mapped_at_creation: false,
        });

        let bgl = device.create_bind_group_layout(&wgpu::BindGroupLayoutDescriptor {
            label: Some("bgl"),
            entries: &[wgpu::BindGroupLayoutEntry {
                binding: 0,
                visibility: wgpu::ShaderStages::FRAGMENT,
                ty: wgpu::BindingType::Buffer {
                    ty: wgpu::BufferBindingType::Uniform,
                    has_dynamic_offset: false,
                    min_binding_size: None,
                },
                count: None,
            }],
        });
        let bind_group = device.create_bind_group(&wgpu::BindGroupDescriptor {
            label: Some("bg"),
            layout: &bgl,
            entries: &[wgpu::BindGroupEntry {
                binding: 0,
                resource: uniform_buf.as_entire_binding(),
            }],
        });

        let pipeline_layout = device.create_pipeline_layout(&wgpu::PipelineLayoutDescriptor {
            label: Some("pl"),
            bind_group_layouts: &[&bgl],
            push_constant_ranges: &[],
        });
        let pipeline = device.create_render_pipeline(&wgpu::RenderPipelineDescriptor {
            label: Some("pipeline"),
            layout: Some(&pipeline_layout),
            vertex: wgpu::VertexState {
                module: &shader, entry_point: "vs_main",
                buffers: &[], compilation_options: Default::default(),
            },
            fragment: Some(wgpu::FragmentState {
                module: &shader, entry_point: "fs_main",
                targets: &[Some(config.format.into())],
                compilation_options: Default::default(),
            }),
            primitive: wgpu::PrimitiveState::default(),
            depth_stencil: None,
            multisample: wgpu::MultisampleState::default(),
            multiview: None,
            cache: None,
        });

        Ok(Self { surface, device, queue, config, pipeline, bind_group, uniform_buf })
    }

    pub fn resize(&mut self, width: u32, height: u32) {
        self.config.width = width.max(1);
        self.config.height = height.max(1);
        self.surface.configure(&self.device, &self.config);
    }

    pub fn draw(&mut self, vp: &Viewport, iter_cap: u32) {
        let u = Uniforms::from_viewport(vp, iter_cap);
        self.queue.write_buffer(&self.uniform_buf, 0, bytemuck::bytes_of(&u));

        let frame = match self.surface.get_current_texture() {
            Ok(f) => f,
            Err(e) => { log::warn!("surface err: {e:?}"); return; }
        };
        let view = frame.texture.create_view(&Default::default());
        let mut enc = self.device.create_command_encoder(&Default::default());
        {
            let mut rp = enc.begin_render_pass(&wgpu::RenderPassDescriptor {
                label: Some("rp"),
                color_attachments: &[Some(wgpu::RenderPassColorAttachment {
                    view: &view, resolve_target: None,
                    ops: wgpu::Operations {
                        load: wgpu::LoadOp::Clear(wgpu::Color::BLACK),
                        store: wgpu::StoreOp::Store,
                    },
                })],
                depth_stencil_attachment: None, timestamp_writes: None, occlusion_query_set: None,
            });
            rp.set_pipeline(&self.pipeline);
            rp.set_bind_group(0, &self.bind_group, &[]);
            rp.draw(0..3, 0..1);
        }
        self.queue.submit(Some(enc.finish()));
        frame.present();
    }
}
```

```rust
pub fn install(
    canvas: &HtmlCanvasElement,
    window: &Window,
    vp: Viewport, iter_cap: u32, renderer: Renderer, fractal: impl Fractal + 'static,
) {
    let state = Rc::new(RefCell::new(AppState { /* fields */ }));

    // 1) pointerdown → dragging = true; last = (x,y)
    // 2) pointermove → if dragging: pan_by_pixels((x-last.x, y-last.y)); dirty=true; last=(x,y)
    // 3) pointerup / pointercancel → dragging = false
    //    canvas.set_pointer_capture_with_... on pointerdown so drag continues off-canvas
    // 4) wheel → preventDefault; factor = if deltaY > 0 { 1.1 } else { 1.0/1.1 };
    //           zoom_toward((x,y), size, factor); dirty = true;
    // 5) ResizeObserver on canvas → resize renderer + update aspect_ratio + dirty

    // render loop via requestAnimationFrame:
    //   if state.dirty: renderer.draw(&vp, iter_cap); state.dirty = false;
    //                   if now - last_url_write_ms > 150ms: state::write_url(...)
    //   window.request_animation_frame(&self_ref);
}
```

Key implementation notes:
- All closures forget() or are held in the state to keep them alive.
- `event.prevent_default()` on wheel to stop page scroll.
- `touch-action: none` on canvas CSS so pointer events aren't intercepted.
- Use `event.client_x()` minus `canvas.get_bounding_client_rect().left()` to get canvas-relative pixel.
- Multiply canvas-relative x,y by `window.device_pixel_ratio()` if we render at DPR-scaled size.

### `src/state.rs`

```rust
use fractal_core::{Fractal, Viewport};

pub struct UrlState {
    pub fractal_id: String,
    pub center: (f64, f64),
    pub zoom: f64,
    pub iter_cap: u32,
}

impl UrlState {
    pub fn parse(hash: &str) -> Option<Self> {
        let s = hash.strip_prefix('#').unwrap_or(hash);
        let mut f = None; let mut cx = None; let mut cy = None;
        let mut z = None; let mut iter = None;
        for kv in s.split('&') {
            if let Some((k, v)) = kv.split_once('=') {
                match k {
                    "f" => f = Some(v.to_string()),
                    "cx" => cx = v.parse().ok(),
                    "cy" => cy = v.parse().ok(),
                    "z" => z = v.parse().ok(),
                    "iter" => iter = v.parse().ok(),
                    _ => {}
                }
            }
        }
        Some(Self { fractal_id: f?, center: (cx?, cy?), zoom: z?, iter_cap: iter? })
    }

    pub fn to_hash(&self) -> String {
        format!("#f={}&cx={}&cy={}&z={}&iter={}",
            self.fractal_id, self.center.0, self.center.1, self.zoom, self.iter_cap)
    }
}

pub fn load_initial(window: &web_sys::Window, fractal: &dyn Fractal) -> (Viewport, u32) {
    let hash = window.location().hash().unwrap_or_default();
    if let Some(u) = UrlState::parse(&hash) {
        if u.fractal_id == fractal.id() {
            let mut vp = fractal.default_view();
            vp.center = u.center;
            vp.zoom = u.zoom;
            return (vp, u.iter_cap);
        }
    }
    (fractal.default_view(), fractal.default_iter_cap())
}

pub fn write_url(window: &web_sys::Window, fractal_id: &str, vp: &Viewport, iter_cap: u32) {
    let h = UrlState {
        fractal_id: fractal_id.to_string(),
        center: vp.center, zoom: vp.zoom, iter_cap,
    }.to_hash();
    if let Ok(history) = window.history() {
        let _ = history.replace_state_with_url(&wasm_bindgen::JsValue::NULL, "", Some(&h));
    }
}

mod tests {

        let parsed = UrlState::parse(&s.to_hash()).unwrap();
```

```rust
pub fn show(message: &str) {
    let Some(window) = web_sys::window() else { return; };
    let Some(doc) = window.document() else { return; };
    let el = doc.get_element_by_id("error-overlay")
        .or_else(|| {
            let el = doc.create_element("div").ok()?;
            el.set_id("error-overlay");
            doc.body()?.append_child(&el).ok()?;
            Some(el)
        });
    if let Some(el) = el {

               <h1>Can't load Fractal Explorer</h1>\
               <p>{}</p>\
               <p>This build requires <a href=\"https://caniuse.com/webgpu\" style=\"color:#8cf\">WebGPU</a>. \
               Try the latest Chrome, Edge, or Firefox Nightly.</p>\
             </div>",
            html_escape(message)
        ));
        el.remove_attribute("hidden").ok();
    }
}
```

## Canvas sizing — DPR awareness

The CSS sets `width:100vw; height:100vh`. We also need to set `canvas.width` / `canvas.height` in **device pixels** for a sharp render. On resize:

```rust
fn resize_canvas(canvas: &HtmlCanvasElement, window: &Window) -> (u32, u32) {
    let dpr = window.device_pixel_ratio();
    let rect = canvas.get_bounding_client_rect();
    let w = (rect.width() * dpr) as u32;
    let h = (rect.height() * dpr) as u32;
    canvas.set_width(w);
    canvas.set_height(h);
    (w, h)
}
```

Call on startup and from a `ResizeObserver` on the canvas.

## Gotchas collected upfront (so we don't re-discover them)

- **`touch-action: none` is required** on the canvas, otherwise pointerdown/pointermove get swallowed by browser gestures on touch devices.
- **DPR sizing**: if we only set CSS size, WebGPU renders at logical-pixel resolution and the output looks blurry on HiDPI. Set `canvas.width = css_width * devicePixelRatio`.
- **`pointer-capture`**: call `canvas.set_pointer_capture(event.pointer_id())` on pointerdown so drag continues if the cursor leaves the canvas.
- **URL writes must be debounced**. `history.replaceState` on every pointermove fires 60×/s and some browsers throttle it, plus it thrashes the address bar. Batch via a flag + rAF, write at most every ~150 ms.
- **Uniform buffer alignment**: WGSL uniform blocks round up to 16 bytes. Our `Uniforms` struct has `vec2<f32>` (8) + `f32` (4) + `f32` (4) + `u32` (4) = 20 bytes; we pad to 32.
- **Closures leak by design in wasm_bindgen**. `.forget()` or hold them in an `Rc<RefCell<_>>` that lives for the program.
- **wgpu 0.20 API surface** has `InstanceDescriptor` fields; don't copy-paste from older examples using 0.17/0.18 shapes.
- **WebGPU needs HTTPS** — localhost is fine, but deploying later needs TLS.
- **trunk + workspace**: either run trunk from `crates/fractal-web/` with a local `Trunk.toml`, or keep it at workspace root and set `data-bin="fractal-web"` on the rust link tag. Pick the root approach for this plan.
